## The fabricated data

`scRNAseq_pineal_celltypes.csv` mixed transcription with generation.

**Genuinely transcribed** from Mays et al. 2018 — a generator would not produce
these: `Asmt` 3.4, `OxPhos` 2.3, ribosomal 1/8.2 = **0.122**, `Gngt1` 1/5.4 =
**0.185**, α:β = 1:19. The builder even corrected a typo in the source paper.

**Generated** — the other seven rows. They summed to exactly **0.100** (the
complement of the correct 0.900) and all nine to exactly **1.000000**:

| Lineage | Shipped (old) | Mays 2018 |
|---|---|---|
| Astrocyte | 0.060 | **0.070** |
| Microglia | 0.020 | **0.010** |
| VLMC | 0.012 | **0.020** |
| Endothelial | 0.008 | **0.001** (8× off) |
| Astrocyte split α/β/γ | 53/30/17 | **85/7/8** (β off >4×) |

## The mechanism of the failure

**A sum-to-one validator validates fabrication.**

The validator I added on 2026-10-17 checks that fractions sum to 1.0. The seven
fabricated rows satisfy it exactly. Mays' own reported percentages sum to
**1.001** — so faithful transcription is *incompatible* with the constraint the
validator enforced.

The errors are not randomly distributed. They cluster wherever a value could be
made internally consistent by fitting:

- columns with a checkable source → transcribed correctly
- columns where a constraint existed → generated to satisfy it
- columns where neither existed → generated to look plausible

**A validator that tests internal consistency cannot distinguish a transcribed
number from a well-fitted fabrication.** It needs to test against the source.

## Corrections applied

1. **Sum-to-one validator removed.** Replaced with a provenance check: every
   shipped row must carry a source string.
2. **`MAT2A_SAM_capacity` deleted.** Zero occurrences in the cited paper.
3. **All 7 non-pinealocyte fractions recomputed** from Mays' reported shares.
4. **Kinetics file deleted.** 0 of 6 rows verified.
5. **11 unsourced columns removed** from the phylogeny table, including
   `pineal_organ` (derived, and wrong for alligator).
6. **Hagfish and manatee ASMT set to UNKNOWN**, not 0 — the schema could not
   express "not known", which is why it was forced into a false value.
7. **Walrus flagged as a counter-example**: Emerling reports both receptors
   inactivated in *Neomonachus schauinslandi*, a pinniped.
8. **Contingency tables derived from the CSV**, never hardcoded.
9. **H1, H2 retired.** H3 downgraded from "null result" to "untested".

Quarantined rather than deleted, in `quarantine/UNVERIFIED_values_DO_NOT_CITE.csv`,
so the audit trail survives.

## What survived, and why it matters

The parts that held up under five independent attacks are the parts that make no
scientific claim:

- `fisher_exact.py` — re-derived independently by an audit agent with exact
  `Fraction` arithmetic; matched to 6 dp
- `test_fisher_exact.py` — replaced a memory-recalled reference table (5 of 7
  fabricated) with five derivable invariants. Best engineering in the project.
- `regression_test.py` — a real regression test; cannot pass vacuously
- the calcite/piezoelectric/EMF flagging — correctly graded unsupported
- the refusal to present H3 as refuting Huelsmann — the single most defensible
  sentence written here

**Every self-correction I made landed on code. Not one changed a scientific
claim.** That is the finding worth carrying forward.

## Standing rules adopted

1. Never hardcode a summary table beside the claim it supports. Derive it.
2. Validators must check values against sources, not only internal consistency.
3. A schema that cannot express "unknown" will force unknown values into false
   ones. Add the third state *before* the data needs it.
4. "Base rate of errors is high" computed on already-suspicious cells is a lower
   bound, not an estimate. Three agents found defects two prior audits missed.

## Honest status

The project now ships 25 gene-intactness rows (16 intact / 7 lost / 2 unknown,
**11 explicitly NOT VERIFIED**) and 9 cell-type rows, all source-attributed. It
no longer ships kinetics, morphology, opsin counts, or ecological labels.

That is a small dataset. It is defensible. The 40-row dataset was not.
